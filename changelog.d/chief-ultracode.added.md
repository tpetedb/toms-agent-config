The chief now starts with Claude Code's ultracode: `config/models.toml` takes an optional `ultracode = true` on an Anthropic seat at effort `xhigh` (refused on openai and on a role whose charter runs as a `subagent`), `just chief` runs the command `tac config launch-command` reads from that file (`claude --agent chief --effort ultracode`), and `tac explain roles.<role>` prints each seat's model, effort, ultracode and launch command. Ultracode uses more tokens and time on every request; delete the key in `config/models.toml` to turn it off.
