A gate child's writes are now an allowlist: its checkout, minus `.agents/`, `.git`, `.claude/`, `.codex/` and the git common dir, and a private scratch folder that is its HOME, TMPDIR and caches, removed afterwards. Code a builder wrote can no longer plant a Claude hook, a LaunchAgent, a shared git hook or a module in the judge's venv for a later unsandboxed run, and Apple Events, LaunchServices and preference writes are denied. The runner's own `git status` gets no write to the tree and finds git on the runner's PATH.
A runner already inside a Seatbelt profile, where profiles cannot nest, now refuses to gate, so this repository's Seatbelt tests skip inside a gate as they do on Linux. The CI scripts make their temporary folder under TMPDIR, so `just verify` passes inside a gate.
