`tac sync` now renders the guard into `.claude/settings.json` and a new `.codex/hooks.json` from `config/hooks.toml`: one hook per event and merged matcher, each an empty environment with a fixed PATH, `/usr/bin/python3 -I` and the stamped `.agents/hooks/run.py` by absolute path, with Codex matched on the tool names it reports (`apply_patch`, `spawn_agent`) and its patches read file by file by the edit checks. The git hooks live in `hooks/git/prek.toml` (ruff, `tac check --staged`, the private scan; `tac check --commit-msg` against `[commits]`; the fast tests and `tac check` before a push), prek is pinned in the dev group, `just hooks-install` installs them, and `tac check` refuses a hook list that differs from `[git]` in `hooks.toml` or a hook that is not a local system command.
