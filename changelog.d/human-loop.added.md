`tac human ask`, `answer`, `render`, `recap` and `verify`, and `tac approve`: the owner's queue lives in `.human/approvals/<id>.json`, `TODO.HUMAN.md` is rendered from it and `.human/todo.toml` byte for byte (`tac human render --check` fails on a hand edit), recaps go to `.human/recap/<UTC basic time>-<slug>.md`, and an approval counts only as a record signed on the host with the runner key or as the owner's own approving review on the pull request's head, so a forged file, an unknown key, a self-authored approval, another head, a replay and a timeout are each refused.
