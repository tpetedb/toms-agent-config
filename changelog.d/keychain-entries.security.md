The runner's two secrets move into the macOS login keychain (build condition C6): its signing key and the `tac-bot` token, and no other name, which the keychain reader refuses before starting `security`. `just runner-keychain` (host only) moves the key file into the keychain, stores the token and removes the file; until then the runner warns on every start. The token reaches only the runner's own git, through the `tac runner credential` helper, which refuses an agent session and a sandboxed caller before it reads the keychain, and its own `gh`, as `GH_TOKEN` in that one child's environment.
