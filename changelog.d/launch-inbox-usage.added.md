`tac launch <harness>` (`just launch`) starts a role's Claude Code or Codex session the way the runner does: headless Claude runs with the settings overlay, project settings only, strict MCP config, JSON output against the contract, turn and budget caps and a chosen session id, never in bare mode, and is refused while an API-key or cloud billing variable is set; the environment is an allowlist, and the generated surfaces are compared with the lock at origin/main first; `--print` shows the command. `tac inbox watch` (`just inbox-watch --once`) performs the effect requests the worker inbox holds after checking schema, policy, approval and lease. `tac usage` (`just usage`) reads the Claude Code statusline's usage windows recorded by `tac usage record` and exits 3 while spawning is paused; every dispatch checks it first. `just adapter-proof` runs the launch and guard-failure tests with no skip and prints both clients' commands.
