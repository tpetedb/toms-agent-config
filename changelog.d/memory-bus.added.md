The memory bus: `tac memory add`, `event`, `search`, `index`, `promote`, `lint` and `schema`, and `tac select`. Records and their supersede, review, decay, correct and conflict events are appended to a live journal in the worker store, a torn line is quarantined and an unknown version refused; status and confidence are derived from the events; promotion into `.agents/memory/` needs a basis recomputed from a verified receipt, review or approval, and the selector gives a stage prompt a deterministic, capped set that never truncates a policy record.
