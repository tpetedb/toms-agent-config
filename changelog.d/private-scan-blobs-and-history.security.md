The private scan reads committed blobs with `git cat-file --batch`, never the checkout and never through gitattributes, as UTF-8 and as UTF-16 in both byte orders, skips only a blob that is binary by content and refuses a Git LFS pointer; `--range BASE..HEAD` scans every blob each commit adds or changes, the tip's tree, every commit message and the branch name, and CI runs it with the pull request's base and head. The terms move to `scripts/private_terms.txt`, hex-encoded and owned by CODEOWNERS, which CI takes from the base with the scan; the scan itself carries no terms and is scanned like any other file.
