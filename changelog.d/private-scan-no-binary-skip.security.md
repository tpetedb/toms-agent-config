The private scan no longer skips any blob as binary: every blob is read as UTF-8 with replacement and as UTF-16 and UTF-32 in both byte orders at every alignment, and a hit prints a window around the term. It finds a Git LFS pointer the way git-lfs does (whitespace trimmed, all three spec URLs, or a version line with an oid line). `--range` scans each commit object whole, author, committer, every other header and the message, and the local scan checks the identity git would record; an `identity` line in `scripts/private_terms.txt` exempts only the owner's exact commit identity in those headers.
