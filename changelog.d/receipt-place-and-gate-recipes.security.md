A committed receipt now counts only in the order folder its signed `order_id` names and only for a revision the pull request brought (or byte for byte as the base already holds it), so a genuine receipt cannot be moved or replayed into another order or change. The runner runs a gate only as `just <recipe> [ids]` from an allowlist, with the justfile named, so no just flag or shell text in a request can choose what runs; CI's `work` job judges orders with the base revision's checker.
