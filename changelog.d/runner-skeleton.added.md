`tac runner`, the host process skeleton: a controller store per repository under the user state directory and never inside the repository, a private Unix socket, and ed25519-signed receipts bound to the repository, revision, run, stage and policy hash, for gates and client probes it runs itself. `tac receipt client` asks it to probe an installed client, and `tac receipt verify-tree` in CI checks committed receipts against `runner.pub` from the base revision, rejecting a replay, an altered field, a candidate's own key and a missing key.
