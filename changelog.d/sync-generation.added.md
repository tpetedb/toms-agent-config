`tac sync` renders each enforced harness's own files from `.agents/` through sandboxed Jinja templates under `templates/adapters/<harness>/`, each naming its output on its first line from an allowlist: `AGENTS.md` from the authored brief in `.agents/context/brief.md`; for Claude Code, `CLAUDE.md` (an `@AGENTS.md` import plus the Claude extras), `.claude/settings.json` (the permission mode, bypass disabled, Edit and Read deny rules and sandbox `denyWrite` on `.agents/**` and every generated path, the sandbox rendered explicitly and failing closed, the telemetry tier and the secret scrub in `env`, an empty `hooks` table for M2), `.claude/agents/<role>.md` and per-skill links in `.claude/skills/`; for Codex, `.codex/config.toml` (the active profile as top-level keys, no `profiles` and no `otel`, analytics and feedback off, command networking off until a proxy is proven) and `.codex/agents/<role>.toml`.
