`tac run <pipeline> --order <id>` (`just run`): the runner runs a pipeline stage by stage as a state machine checkpointed after every transition in the controller store, with `--resume <run>` and `--dry-run`. Agent stages render their prompt from the upstream envelopes, start the client headless on the subscription and judge the result against its contract with one repair pass; gates run through the runner's sandboxed gate and are rerun at most `retry.max` times after a repair; effect stages go through the effect journal and wait for the owner's signed approval; the `land` stage asks the owner to merge with `gh pr review <N> --approve && gh pr merge <N> --squash --match-head-commit <sha>` and prints the same line. A pipeline that is not enabled, or whose gate still waits on a milestone, is refused.
