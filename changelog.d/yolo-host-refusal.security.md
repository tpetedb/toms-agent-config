`yolo`, and any profile whose isolation is `container` or `disposable-container`, is refused as the active profile by `tac config check`, `tac sync` and `tac check` unless the process runs inside a container, proven by a root-owned `/.dockerenv` (Docker) or `/run/.containerenv` (podman) and never by an environment variable. Before, a host render of `yolo` wrote `bypassPermissions` with the sandbox off. Every profile file is still validated as a file, and `tac config check` names the marker it took as proof.
