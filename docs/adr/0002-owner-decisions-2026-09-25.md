# ADR 0002: The owner's open decisions, taken on 2026-09-25

Status: Accepted, 2026-09-25. Taken by the chief of staff on the owner's delegation ("Permission to make the decisions needed and do the Bootstrap pr"), with the basis `owner-via-chief` that docs/DESIGN.md section 7 allows for design questions. The owner can reverse any line below with a later record that supersedes this one.

## Context

The design left twenty items to the owner in `TODO.HUMAN.md`, each with the board's recommendation and the milestone that waits on it. The milestones built so far sit on stacked branches with open pull requests: #1 (`docs/design` into `main`), #2 (`tac/m0-bootstrap` into `docs/design`), #4 (`tac/m1-core` into `tac/m0-bootstrap`) and #5 (`tac/m2-hooks-human` into `tac/m1-core`). Two items blocked `main` from taking any of them: the history of those branches carries an earlier private scan's term list in plain text (Q21), and the owner's commits carried an address that is itself on that list (Q22). The rest were waiting on milestones from M0 to M8.

On 2026-09-25 the owner delegated the open decisions to the chief of staff and asked for one bootstrap pull request. What only the owner can do on GitHub or on the host (create an identity, apply a ruleset, trust a client, provision a key) cannot be delegated, and is not decided here.

## Decision

Nineteen of the twenty items are decided as follows, grouped as `TODO.HUMAN.md` groups them.

**Scope and providers.**

- Q18, release 1 scope: Claude Code and Codex enforced, the standard profile only. The enterprise and yolo profiles, containers, and the Copilot, opencode, pi and Gemini harnesses move to release 1.1.
- Q9, licence: MIT, "Copyright (c) 2026 Tom Peters", in `LICENSE` at the root.
- Q10, providers: Claude (a Max subscription) and OpenAI. No Google or Copilot seat is assumed; Gemini and Copilot are instructions-only in release 1.
- Q7, Copilot: the CLI only, in release 1.1. No IDE, cloud agent or code review surface.

**Governance.**

- Q5, the board: Opus sits as a director only through a separate fresh session, never the chief's own. Fable compiles the tally, a majority of three decides, the dissent is recorded, and a safety veto goes to the owner.
- Q6, the chief's authority: the chief opens issues and pull requests and pushes branches as the machine account, through the runner. Merges and releases are the owner's own action.

**Profiles, billing, secrets, telemetry.**

- Q3, yolo: unattended only inside a disposable container with an egress allowlist, never with unrestricted host access.
- Q16, headless Claude billing: the subscription only, never `--bare`, and no API key.
- Q17, `agents.env`: outside the repository.
- Q15, telemetry: the partial tier on the owner's Mac, which keeps Remote Control and auto mode working; the full kill set inside containers and CI.

**Standards and memory.**

- Q4, commits: "what and why, one line", with a subject of at most 72 characters, rather than Conventional Commits.
- Q20, the root `AGENTS.md`: generated by `tac sync` from `.agents/context/brief.md`, as M1 builds it. A hand edit to it is a red `tac check`.
- Q8, retention: raw sessions and traces are folded after 30 days, and the folded digests are committed.
- Q13, Soda: postponed to release 1.1. If data work needs it sooner, the Apache-2.0 v3 line comes in as an opt-in extra.

**The public repository's history and identity.**

- Q21, the term list in old history: re-cut, instead of a known-history exception in the scan. `main` takes the design, M0 and M1 as one squashed commit on `bootstrap/2026-09-25`, which holds no plain-text term list. Pull requests #1, #2 and #4 close as superseded, and their branches are deleted once no open pull request depends on them. GitHub keeps a closed pull request's commits readable, so the old list stays visible there; the owner accepts that as low sensitivity, since the list names words to keep out of the repository and is not a secret. No scan exception is added.
- Q22, the commit identity: this repository commits under the GitHub noreply address, `177582730+tpetedb@users.noreply.github.com`, set in its local git config. The `identity` line in `scripts/private_terms.txt` stays until no open branch holds a commit under the old address, and then goes.

**Skills and third-party material.**

- Q1, ponytail: vendor [DietrichGebert/ponytail](https://github.com/DietrichGebert/ponytail) (MIT), trimmed, as an opt-in skill for builders, with its notice in `THIRD_PARTY.md` when it lands.
- Q2, user-level third-party skills: moved aside on the owner's machine, to `~/.agents/skills-disabled`, so they load into no session next to TAC's own. The caveman package stays excluded.
- Q19, patterns from a private repository: allowed only as patterns re-implemented from scratch in this repository (the `TODO.HUMAN.md` format, a gate runner for `just`, an em-dash check), each with an authorship line. No code is copied from the private repository.

**Not decided here, still the owner's own actions.**

- Q14, the agent identity: create the machine account or GitHub App, then apply the no-bypass ruleset with `tac github apply`.
- The one-time trust steps on the owner's machine: Codex project trust and `/hooks`, Claude workspace trust, `mise trust`, and the runner key.

## Consequences

- `TODO.HUMAN.md` ticks the nineteen decided items and records each answer under its item. Q14 and the one-time steps stay open, and M0 still cannot pass before Q14.
- `LICENSE` carries the MIT text; `README.md` and `THIRD_PARTY.md` name it.
- docs/DESIGN.md changes to match: sections 2.1 and 2.2 call `AGENTS.md` generated, the release section names the release 1 scope, and section 8 describes the re-cut instead of an exception.
- The bootstrap pull request's base, `main`, predates every gate script, so its `gates` job runs the candidate's copies with a warning, as the bootstrap exception in section 8 says, and it needs the owner's direct review of its gate scripts and workflow. The range scan over it reads a single commit.
- `tac/m1-core` stays while #5 builds on it; the other superseded branches go once nothing open depends on them.
- The configuration already matches Q4, Q8 and Q13 (`max_subject = 72`, `retention_days = 30`, `soda-v3-optional`). Comments under `.agents/` that still call these open change through their own order, since `.agents/` is read-only to agents.
- Each answer binds the milestone that `TODO.HUMAN.md` names under its item; nothing here changes code in this commit.
